## Init Project and Hardhat

```
    npm init -y
    pnpm add -D hardhat
    npx hardhat init
```

## Setup Prettier

- Install Solidity extension
- Add `.prettierrc` and `.prettierrcignore` at root
- Add format script to package.json

```
    pnpm install --save-dev prettier prettier-plugin-solidity
```

## Setup Dotenv

- Create `.env` at root

```
    pnpm i dotenv -D
```

## Install OpenZeppelin

```
    pnpm install @openzeppelin/contracts
```
